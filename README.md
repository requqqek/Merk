# Merk — система автоматической проверки учебных заданий

Клиент-серверная информационная система для автоматизации проверки учебных заданий,
ориентированная на обучение программированию. Состоит из мобильного приложения
**Merk** (Android) и серверной части **MerkApi** (ASP.NET Core).

## Возможности

**Студент**
- Регистрация по коду приглашения и вход по логину и паролю
- Просмотр списка заданий с фильтрацией по статусу
- Выполнение заданий 4 типов: выбор одного / нескольких вариантов, текстовый ответ, программный код
- Мгновенная автоматическая проверка и просмотр персональной статистики

**Преподаватель**
- Создание, редактирование и удаление заданий (с выбором учебной группы)
- Создание учебных групп, добавление и удаление студентов
- Формирование кодов приглашения для регистрации
- Просмотр попыток сдачи и сводной статистики с фильтрацией по группе и студенту

## Технологии

- **Клиент:** Android, Kotlin, Retrofit + OkHttp, Coroutines, Material Design
- **Сервер:** ASP.NET Core, Entity Framework Core, SQLite, REST API
- **Безопасность:** хеширование паролей BCrypt, шифрование персональных данных (AES),
  ограничение попыток входа, разграничение прав по ролям (152-ФЗ), HTTPS

## Установка

1. Скачайте файл `merk.apk` из раздела **Releases**.
2. На Android-устройстве разрешите установку из неизвестных источников.
3. Откройте `merk.apk` и установите приложение.
4. Сервер уже развёрнут по адресу `https://requqqek-api.ru` — дополнительная настройка не требуется.

> Минимальная версия Android — 8.0 (API 26).

## Тестовые учётные записи

| Роль | Логин | Пароль |
|------|-------|--------|
| Преподаватель | `teacher` | `teacher123` |
| Студент | `student1` | `student123` |

Коды приглашения для регистрации студента: `ISP100` (группа ИСП-100), `ISP101` (ИСП-101).

## Как пользоваться

**Студент:** войдите или зарегистрируйтесь по коду приглашения → вкладка «Задания» →
выберите задание → выполните и отправьте ответ → результат и статистика появятся сразу.

**Преподаватель:** войдите → вкладка «Настройки» для создания групп, заданий, добавления
студентов и генерации кодов приглашения → вкладка «Статистика» для просмотра успеваемости.

## Сборка из исходников

```bash
# Клиент (Android Studio): Build → Generate Signed Bundle / APK → APK
# Сервер:
dotnet publish -c Release -o publish
dotnet MerkApi.dll
```
